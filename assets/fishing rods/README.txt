FISHING RODS - 5 designs (same navy outline as the main character)

Each folder:  icon_16.png  (inventory / hotbar)   icon_32.png  (shop / journal / menus)
05_lantern_rod also has icon_16_glow_anim_4f.png and icon_32_glow_anim_4f.png
(4-frame glowing animation, play at ~5 FPS, loop).

all_rods_16.png / all_rods_32.png = all five in one row (for an atlas).

Suggested progression:
 1 Bamboo Rod      - Grandpa's old rod, starter. Float/bobber, no reel.
 2 Wooden Rod      - first upgrade, simple reel + hook.
 3 Fiberglass Rod  - stronger, red & white spoon lure.
 4 Carbon Pro Rod  - pro rod, gold reel, minnow lure.
 5 Lantern Rod     - legendary, glowing lantern lure (catches night fish / fits the game name).
